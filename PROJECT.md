# Image viewer

This is browser-based image viewer for file manager level usage. You can accosiate it with image file extensions.
When user select this action, browser with parameter is called and opens viewer html file with toolbar and image frame for all space available in viewport.

Viewer has three ways to control image view: mouse buttons, keys and toolbar with buttons.

## Actions

 - Zoom in. '+' key, mouse scroll weel
 - Zoom out. '-' key, mouse scroll weel
 - Zoom all. 'a' key, mouse middle button
 - Pan. arrows keys, mouse drag with left button
